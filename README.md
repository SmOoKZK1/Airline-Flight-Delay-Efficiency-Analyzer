# Airline Flight Delay & Efficiency Analyzer

This project focuses on transforming raw aviation data into strategic business intelligence to mitigate the multi-billion dollar impact of flight delays. It features a complete end-to-end data engineering and analytics pipeline, moving from raw data ingestion to predictive risk assessment.
1. Data Engineering: Developed a robust Data Warehouse (DWH) using a Star Schema architecture (Fact_Delays and multiple Dimension tables) in MySQL to optimize query performance for over 171,000 records.

2. Analytics & ML: Integrated Python (Pandas, Scikit-Learn) to perform exploratory data analysis and deployed Random Forest and Z-Score models to transition from descriptive reporting to predictive intelligence.

3. Visualization: Designed an interactive Power BI executive dashboard that translates complex machine learning outputs into intuitive scorecards, allowing stakeholders to drill down into carrier performance and operational bottlenecks.
